Return only the supplied strict JSON schema (`additionalProperties: false`). Preserve page boundaries. If identity evidence is insufficient, use `insufficient`; do not silently merge.

Include the correlation ID, patient ID, document ID, prompt version `document-classifier/v1`, and provenance for every non-null classification fact.
